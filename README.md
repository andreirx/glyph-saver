# Glyph Saver

A macOS screensaver that writes proverbs in handwriting — an invisible pen
draws each letter stroke by stroke until the whole proverb stands on screen.

The contemplative form of [Glypher](https://github.com/andreirx/zap-engine)
(`examples/glypher`): same hand-authored glyph strokes, same cursive flow,
same bump-mapped leather background swept by the pen's light, same particle
celebrations — without the player. Native Swift + Metal (renderer adapted
from ZapZap, EDR-ready `rgba16Float` pipeline); no engine, no web view.

## Status

Speccing / early implementation. See `docs/VISION.md` and `docs/PLAN.md`.

## Build & install (personal use — no signing)

Requires Xcode Command Line Tools (`swiftc`). Then:

```bash
swift test           # core logic tests
scripts/build.sh     # → build/GlyphSaver.saver
scripts/install.sh   # → ~/Library/Screen Savers/ + reload
```

Select "GlyphSaver" in System Settings → Screen Saver.

## Data provenance

`data/glyphs_baked.json` (62 glyph stroke sets) and `data/sayings.json`
(31 proverbs) are copied from `zap-engine/examples/glypher/data/`; the leather
background + normal map in `assets/` from the same example's `public/assets/`.
The glyph file is generated by the zap-engine glyph editor — never hand-edited
here. Renderer code in `Sources/Saver/` is adapted from ZapZap (same author).
